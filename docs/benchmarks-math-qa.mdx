**MathQA** 基准包含 37,000 道多选数学题，评估 LLM 的数学推理能力。更多信息见 [MathQA 数据集](https://arxiv.org/pdf/1905.13319.pdf)。

<Info>
`MathQA` was constructed from the AQuA dataset, which contains over 100K **GRE- and GMAT-level** math word problems.
</Info>

## 参数

There are **TWO** optional arguments when using the `MathQA` benchmark:

- [Optional] `tasks`: a list of tasks (`MathQATask` enums), which specifies the subject areas for model evaluation. By default, this is set to all tasks. The list of `MathQATask` enums can be found [here](#mathqa-tasks).
- [可选] `n_shots`：用于少样本学习的示例数量。**默认设为 5**，**不能超过 5**。

## 用法

The code below assesses a custom `mistral_7b` model ([click here](/guides/guides-using-custom-llms) to learn how to use ANY custom LLM) on geometry and probability in `MathQA` using 3-shot prompting.

```python
from deepeval.benchmarks import MathQA
from deepeval.benchmarks.tasks import MathQATask

# Define benchmark with specific tasks and shots
benchmark = MathQA(
    tasks=[MathQATask.PROBABILITY, MathQATask.GEOMETRY],
    n_shots=3
)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

该基准的 `overall_score` 范围为 0 到 1，1 表示完美表现，0 表示全部答错。模型分数基于**精确匹配**，通过确定模型给出精确正确选项的多选题占总题数的比例来计算。

<Tip>
因此，使用更多少样本提示（`n_shots`）可以大幅提升模型以精确正确格式生成答案的稳健性，并提高总分。
</Tip>

## MathQA Tasks

The `MathQATask` enum classifies the diverse range of categories covered in the MathQA benchmark.

```python
from deepeval.benchmarks.tasks import MathQATask

math_qa_tasks = [MathQATask.PROBABILITY]
```

Below is the comprehensive list of available tasks:

- `PROBABILITY`
- `GEOMETRY`
- `PHYSICS`
- `GAIN`
- `GENERAL`
- `OTHER`

## 常见问题

<AccordionGroup>
<Accordion title="What does the MathQA benchmark measure?">
MathQA assesses an LLM's multi-step mathematical reasoning across 37K English multiple-choice math word problems spanning diverse domains such as probability and geometry. See the [benchmarks introduction](/docs/benchmarks-introduction) for how scoring works across benchmarks.
</Accordion>
<Accordion title="How is MathQA scored?">
Scoring is based on **exact matching**: the `overall_score` is the proportion of questions for which the model produces the precise correct multiple-choice answer (e.g. 'A' or 'C') out of the total. It ranges from 0 to 1, where 1 signifies perfect performance.
</Accordion>
<Accordion title="What is the default n_shots for MathQA?">
It defaults to `5` and cannot exceed that. Use the `n_shots` argument to lower it for few-shot prompting.
</Accordion>
<Accordion title="Which tasks can I evaluate with MathQA?">
Pass a list of `MathQATask` enums to the `tasks` argument to target specific subject areas. Available tasks are `PROBABILITY` , `GEOMETRY` , `PHYSICS` , `GAIN` , `GENERAL` , and `OTHER` . By default, all tasks are evaluated.
</Accordion>
<Accordion title="Can using more few-shot prompts improve the MathQA score?">
Yes. Utilizing more few-shot prompts via `n_shots` can greatly improve the model's robustness in generating answers in the exact correct format and boost the `overall_score` .
</Accordion>
<Accordion title="How do I run MathQA on a custom LLM?">
Define the benchmark, then call `evaluate()` with your model and read `overall_score` . See [benchmarking your LLM](/docs/benchmarks-introduction#benchmarking-your-llm) to learn how to use any custom LLM.
</Accordion>
</AccordionGroup>
