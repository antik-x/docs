**标签**：LLM-as-a-judge · 自定义 · 单轮 · 多模态

图像有用性（image helpfulness）指标评估图像对**帮助用户理解文本**的效果如何，包括提供额外洞见、澄清复杂概念或支撑文本细节。`deepeval` 的图像有用性指标是会自我解释的 MLLM-Eval，会输出指标分数的理由。

<Info>
图像有用性评估包含文本以及随附检索或生成图像的 MLLM 响应。
</Info>

## Required Arguments

要使用 `ImageHelpfulness`，你需要在创建 [`LLMTestCase`](/docs/evaluation-test-cases#llm-test-case) 时提供以下参数：

- `input`
- `actual_output`

<Note>
记住 `LLMTestCase` 的 `actual_output` 是字符串和 `Image` 对象的列表。如果实际输出中提供了多张图片，最终分数将是各图片有帮助度分数的平均值。
</Note>

`input` 和 `actual_output` 是创建 `LLMTestCase` 所必需的（因此也是所有指标必需的），即使它们可能不用于指标计算。更多信息请阅读下文 [How Is It Calculated](#how-is-it-calculated) 一节。

```python
from deepeval.test_case import LLMTestCase, MLLMImage
from deepeval.metrics import ImageHelpfulnessMetric

metric = ImageHelpfulnessMetric(
    threshold=0.7,
    include_reason=True,
)
m_test_case = LLMTestCase(
    input=f"Provide step-by-step instructions on how to fold a paper airplane.",
    # Replace with your MLLM app output
    actual_output=f"""
        1. Take the sheet of paper and fold it lengthwise:
        {MLLMImage(url="./paper_plane_1", local=True)}
        2. Unfold the paper. Fold the top left and right corners towards the center.
        {MLLMImage(url="./paper_plane_2", local=True)}
        ...
    """
)


evaluate(test_cases=[m_test_case], metrics=[metric])
```

- [Optional] `threshold`: a number representing the minimum passing threshold. Can also be set to `None`（TypeScript 中为 `null`） to run the metric in [score-only mode](/docs/metrics-introduction#metric-thresholds). Defaulted to `0.5`.
- [可选] `strict_mode`：布尔值，设为 `True`（TypeScript 中为 `true`）时，把指标分数强制为二元：完美为 1，否则为 0。它还会覆盖当前阈值并将其设为 1。默认为 `False`（TypeScript 中为 `false`）。
- [可选] `async_mode`：布尔值，设为 `True` 时，启用[`measure()` 方法内的并发执行](/docs/metrics-introduction#measuring-metrics-in-async)。默认为 `True`。
  
- [可选] `verbose_mode`：布尔值，设为 `True`（TypeScript 中为 `true`）时，把计算该指标所用的中间步骤打印到控制台，具体见 [How Is It Calculated](#how-is-it-calculated) 一节。默认为 `False`（TypeScript 中为 `false`）。
- [Optional] `max_context_size`: a number representing the maximum number of characters in each context, as outlined in the [How Is It Calculated](#how-is-it-calculated) section. Defaulted to `None`（TypeScript 中为 `null`）.
- [可选] `flaky`：布尔值，设为 `True`（TypeScript 中为 `true`）时，[把指标标记为 flaky](/docs/metrics-introduction#flaky-metrics)。默认为 `False`（TypeScript 中为 `false`）。

## How Is It Calculated?

`ImageHelpfulness` 的分数按以下方式计算：

1. **单张图像有用性**：每张图像的有用性分数基于图像正上方与正下方的文本，受 `max_context_size`（字符数）限制。若未提供 `max_context_size`，则使用所有可用文本。公式为：

$$
H_i = f(\text{Context}_{\text{above}}, \text{Context}_{\text{below}}, \text{Image}_i)
$$

2. **最终分数**：整体的 `ImageHelpfulness` 分数是所有图像各自有用性分数的平均：

$$
O = \frac{\sum_{i=1}^n H_i}{n}
$$

## FAQs

<AccordionGroup>
<Accordion title="我生成的图像真的在为答案增值吗？">
这正是 `ImageHelpfulness` 度量的东西——每张图像是否有助于理解（提供洞见、澄清概念、支撑文本），还是只是装饰或冗余。阅读 `metric.reason` 可查看每张图像的判定。
</Accordion>
<Accordion title="图像有用性与图像连贯性、图像引用有何区别？">
有用性是*价值*（图像是否增进理解？）；[`ImageCoherence`](/docs/multimodal-metrics-image-coherence) 是*对齐*（是否契合叙述？）；[`ImageReference`](/docs/multimodal-metrics-image-reference) 是*引用*（文本是否提到它？）。图像可能连贯却毫无价值。
</Accordion>
<Accordion title="回复中穿插多张图像时如何打分？">
每个 `MLLMImage` 依据其紧邻上下文打分，最终分数是**平均值**（ `O = (ΣH_i) / n` ）。用 `max_context_size` 限制每次判定所用的相邻文本量。
</Accordion>
<Accordion title="图像有用性分数低说明什么？">
模型在插入无助于理解的图像——通用的图库风格图片、对文本的重复，或与其步骤只有松散关联的图像。它们可能连贯、也被引用了，只是*没用*。
</Accordion>
</AccordionGroup>
