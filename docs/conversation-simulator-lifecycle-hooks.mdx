---
title: Lifecycle Hooks
sidebarTitle: "生命周期钩子"
---

`ConversationSimulator` 提供了 `on_simulation_complete` 钩子，让你在单个测试用例的模拟完成时执行自定义逻辑。这让你可以在每个 `ConversationalTestCase` 生成后立即处理它，而不必等待所有模拟完成。

## Supported Arguments

钩子函数接收两个参数：

- `test_case`：已完成的 `ConversationalTestCase` 对象，包含所有轮次和元数据。
- `index`：被模拟的对应金标（golden）的索引（**模拟期间保持顺序**）。

## Example

```python
from deepeval.simulator import ConversationSimulator
from deepeval.test_case import ConversationalTestCase

def handle_simulation_complete(test_case: ConversationalTestCase, index: int):
    print(f"Conversation {index} completed with {len(test_case.turns)} turns")

conversational_test_cases = simulator.simulate(
    conversational_goldens=[golden1, golden2, golden3],
    on_simulation_complete=handle_simulation_complete
)
```

## Common Use Cases

### Result Storage

大批量模拟时，每段对话在完成后立即持久化会更容易处理。

```python
def save_completed_simulation(test_case, index):
    database.save(
        id=f"simulation-{index}",
        turns=[turn.model_dump() for turn in test_case.turns],
        scenario=test_case.scenario,
    )

simulator.simulate(
    conversational_goldens=goldens,
    on_simulation_complete=save_completed_simulation,
)
```

### Progress Logging

进度日志在批量模拟运行时为你提供轻量级的可观测性。

```python
def print_summary(test_case, index):
    print(f"Completed simulation {index}: {len(test_case.turns)} turns")

simulator.simulate(
    conversational_goldens=goldens,
    on_simulation_complete=print_summary,
)
```

<Tip>
使用 `async_mode=True` 时，由于并发执行，对话可能以任意顺序完成。使用 `index` 参数追踪每个测试用例对应的金标。
</Tip>

## FAQs

<AccordionGroup>
<Accordion title="How do I process each conversation as it finishes instead of waiting for the whole batch?">
将 `on_simulation_complete` 钩子传给 `simulate`。它在每个 `ConversationalTestCase` 生成时立即触发，让你无需等待整批完成即可持久化、检查或后处理结果。
</Accordion>
<Accordion title="What arguments does the hook receive?">
两个：已完成的 `test_case`（包含所有轮次和元数据的 `ConversationalTestCase`）和被模拟金标的 `index`。
</Accordion>
<Accordion title="With async_mode on, how do I know which golden a result belongs to?">
使用 `index` 参数。在 `async_mode=True` 下对话可能以任意顺序完成，因此 `index` 是你将每个测试用例映射回其源金标的方式。
</Accordion>
</AccordionGroup>
