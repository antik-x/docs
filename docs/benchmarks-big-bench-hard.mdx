**BIG-Bench Hard** 是 BIG-Bench 中更具挑战性任务的子集，所有任务均为多选题。更多信息见 [BIG-Bench Hard 论文](https://github.com/suzgunmirac/BIG-Bench-Hard)。

## 参数

使用 `BigBenchHard` 基准时有**三个**可选参数：

- [可选] `tasks`：任务列表（`BigBenchHardTask` 枚举），指定模型评估的主题领域。默认为所有任务。`BigBenchHardTask` 枚举列表见[这里](#big-bench-hard-tasks)。
- [可选] `n_shots`：用于少样本学习的示例数量。**默认设为 5**，**不能超过 5**。
- [可选] `enable_cot`：布尔值，决定评估是否使用 CoT 提示。默认设为 `True`。

<Info>
**思维链（CoT）提示**是一种让模型表达其推理过程以得出答案的方法。而**少样本提示**是在预测前向模型提供少量示例（"shots"）供其学习的方法。两者结合时，少样本提示与 CoT 可以显著提升表现。关于 CoT 的更多内容见[这里](https://arxiv.org/abs/2201.11903)。
</Info>

## 用法

下面的代码评估自定义 `mistral_7b` 模型（[点击这里](/docs/benchmarks-introduction#benchmarking-your-llm)了解如何使用**任意**自定义 LLM），使用 3-shot CoT 提示评估其在 `BigBenchHard` 布尔表达式与因果判断任务上的表现。

```python
from deepeval.benchmarks import BigBenchHard
from deepeval.benchmarks.tasks import BigBenchHardTask

# Define benchmark with specific tasks and shots
benchmark = BigBenchHard(
    tasks=[BigBenchHardTask.BOOLEAN_EXPRESSIONS, BigBenchHardTask.CAUSAL_JUDGEMENT],
    n_shots=3,
    enable_cot=True
)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

该基准的 `overall_score` 范围为 0 到 1，1 表示完美表现，0 表示全部答错。模型分数基于**精确匹配**，通过确定模型给出精确正确选项的多选题占总题数的比例来计算。

与使用多选题的基准相比，BBH 答案呈现出更丰富的多样性，因为 BBH 中不同任务需要不同类型的输出（例如布尔表达式任务输出布尔值，算术任务输出数字）。要提升基准表现，采用 **CoT** 提示会极其有效。

<Tip>
使用更多少样本示例（`n_shots`）可以大幅提升模型以精确正确格式生成答案的稳健性，并提高总分。
</Tip>

## BIG-Bench Hard Tasks

`BigBenchHardTask` 枚举分类了 BIG-Bench Hard 基准涵盖的多样化任务。

```python
from deepeval.benchmarks.tasks import BigBenchHardTask

big_tasks = [BigBenchHardTask.BOOLEAN_EXPRESSIONS]
```

## 常见问题

<AccordionGroup>
<Accordion title="What does the BigBenchHard benchmark measure?">
BIG-Bench Hard 包含 **23 个挑战性** BIG-Bench 任务，此前的语言模型评估在这些任务上未能超越人类评分者的平均水平。`BigBenchHard` 同时使用少样本和思维链（CoT）提示技术评估模型。
</Accordion>
<Accordion title="Which tasks can I run with BigBenchHard?">
你可以向 `tasks` 参数传入一组 `BigBenchHardTask` 枚举，例如 `BOOLEAN_EXPRESSIONS` 或 `CAUSAL_JUDGEMENT` 。默认评估全部 23 个任务。
</Accordion>
<Accordion title="How is BigBenchHard scored?">
`overall_score` 范围为 0 到 1，是按各任务目标标签计算的预测正确比例。使用**精确匹配**评分器，尽管 BBH 的答案差异很大（例如布尔表达式任务输出布尔值，算术任务输出数字）。评分详见[基准介绍](/docs/benchmarks-introduction)。
</Accordion>
<Accordion title="What is the default n_shots for BigBenchHard?">
`n_shots` 参数严格范围为 0-3，默认为 `3` 。使用更多少样本示例可以提升模型以精确正确格式生成答案的稳健性。
</Accordion>
<Accordion title="Does BigBenchHard support chain-of-thought prompting?">
可以。`enable_cot` 参数是决定是否使用 CoT 提示的布尔值，默认为 `True` 。采用 CoT 提示对提升 BBH 的基准表现极其有效。
</Accordion>
<Accordion title="How do I run BigBenchHard on a custom LLM?">
把你的模型包装进 `DeepEvalBaseLLM` ，用 `BigBenchHard(tasks=[...], n_shots=3, enable_cot=True)` 创建基准，调用 `benchmark.evaluate(model=mistral_7b)` 后读取 `benchmark.overall_score` 。使用任意自定义 LLM 见[基准测试指南](/docs/benchmarks-introduction#benchmarking-your-llm)。
</Accordion>
</AccordionGroup>
