**BIG-Bench Hard** 是 BIG-Bench 中更具挑战性任务的子集，所有任务均为多选题。更多信息见 [BIG-Bench Hard 论文](https://github.com/suzgunmirac/BIG-Bench-Hard)。

## 参数

There are **THREE** optional arguments when using the `BigBenchHard` benchmark:

- [Optional] `tasks`: a list of tasks (`BigBenchHardTask` enums), which specifies the subject areas for model evaluation. By default, this is set to all tasks. The list of `BigBenchHardTask` enums can be found [here](#big-bench-hard-tasks).
- [可选] `n_shots`：用于少样本学习的示例数量。**默认设为 5**，**不能超过 5**。
- [可选] `enable_cot`：布尔值，决定评估是否使用 CoT 提示。默认设为 `True`。

<Info>
**Chain-of-Thought (CoT) prompting** is an approach where the model is prompted to articulate its reasoning process to arrive at an answer. Meanwhile, **few-shot prompting** is a method where the model is provided with a few examples (or "shots") to learn from before making predictions. When combined, few-shot prompting and CoT can significantly enhance performance. You can learn more about CoT [here](https://arxiv.org/abs/2201.11903).
</Info>

## 用法

The code below assesses a custom `mistral_7b` model ([click here to learn how to use **ANY** custom LLM](/docs/benchmarks-introduction#benchmarking-your-llm)) on Boolean Expressions and Causal Judgement in `BigBenchHard` using 3-shot CoT prompting.

```python
from deepeval.benchmarks import BigBenchHard
from deepeval.benchmarks.tasks import BigBenchHardTask

# Define benchmark with specific tasks and shots
benchmark = BigBenchHard(
    tasks=[BigBenchHardTask.BOOLEAN_EXPRESSIONS, BigBenchHardTask.CAUSAL_JUDGEMENT],
    n_shots=3,
    enable_cot=True
)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

该基准的 `overall_score` 范围为 0 到 1，1 表示完美表现，0 表示全部答错。模型分数基于**精确匹配**，通过确定模型给出精确正确选项的多选题占总题数的比例来计算。

BBH answers exhibit a greater variety of answers compared to benchmarks that use multiple-choice questions, since different tasks in BBH require different types of outputs (for example, boolean values in boolean expression tasks versus numbers in arithmetic tasks). To enhance benchmark performance, employing **CoT** prompting will prove to be extremely helpful.

<Tip>
Utilizing more few-shot examples (`n_shots`) can greatly improve the model's robustness in generating answers in the exact correct format and boost the overall score.
</Tip>

## 常见问题

<AccordionGroup>
<Accordion title="What does the BigBenchHard benchmark measure?">
BIG-Bench Hard comprises **23 challenging** BIG-Bench tasks where prior language model evaluations did not outperform the average human rater. `BigBenchHard` evaluates models using both few-shot and chain-of-thought (CoT) prompting techniques.
</Accordion>
<Accordion title="Which tasks can I run with BigBenchHard?">
You can pass a list of `BigBenchHardTask` enums to the `tasks` argument, for example `BOOLEAN_EXPRESSIONS` or `CAUSAL_JUDGEMENT` . By default, all 23 tasks are evaluated.
</Accordion>
<Accordion title="How is BigBenchHard scored?">
The `overall_score` ranges from 0 to 1 and is the proportion of total correct predictions according to the target labels for each task. The **exact match** scorer is used, even though BBH answers vary widely (e.g. booleans for boolean expression tasks versus numbers for arithmetic tasks). See the [benchmarks introduction](/docs/benchmarks-introduction) for more on scoring.
</Accordion>
<Accordion title="What is the default n_shots for BigBenchHard?">
The `n_shots` argument ranges strictly from 0-3 and is set to `3` by default. Using more few-shot examples can improve the model's robustness in generating answers in the exact correct format.
</Accordion>
<Accordion title="Does BigBenchHard support chain-of-thought prompting?">
Yes. The `enable_cot` argument is a boolean that determines whether CoT prompting is used, and it is set to `True` by default. Employing CoT prompting is extremely helpful for boosting benchmark performance on BBH.
</Accordion>
<Accordion title="How do I run BigBenchHard on a custom LLM?">
Wrap your model in `DeepEvalBaseLLM` , create a benchmark with `BigBenchHard(tasks=[...], n_shots=3, enable_cot=True)` , and call `benchmark.evaluate(model=mistral_7b)` before reading `benchmark.overall_score` . See the [benchmarking guide](/docs/benchmarks-introduction#benchmarking-your-llm) for using any custom LLM.
</Accordion>
</AccordionGroup>
