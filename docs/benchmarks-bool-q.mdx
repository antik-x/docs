**BoolQ** 是一个阅读理解数据集，包含 16K 个是非题（验证集 3.3K）。BoolQ 的特点是自然出现的问题，即它们在无提示的设置下产生，每个问题都配有一段文章。

<Info>
要了解数据集及其构建方式的更多信息，可[阅读原始论文](https://arxiv.org/pdf/1905.10044)。
</Info>

## Arguments

使用 `BoolQ` 基准时有**两个**可选参数：

- [可选] `n_problems`：用于模型评估的题目数量。默认为 3270（所有题目）。
- [可选] `n_shots`：用于少样本学习的示例数量。**默认设为 5**，**不能超过 5**。

## Usage

下面的代码评估自定义 `mistral_7b` 模型（[点击这里](/docs/benchmarks-introduction#benchmarking-your-llm)了解如何使用**任意**自定义 LLM），使用 3-shot CoT 提示评估其在 `BoolQ` 10 道题上的表现。

```python
from deepeval.benchmarks import BoolQ

# Define benchmark with n_problems and shots
benchmark = BoolQ(
    n_problems=10,
    n_shots=3,
)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

该基准的 `overall_score` 范围为 0 到 1，1 表示完美表现，0 表示全部答错。模型分数基于**精确匹配**，通过确定模型给出精确正确答案（即 'Yes' 或 'No'）的题目占总题数的比例来计算。

<Tip>
因此，使用更多少样本提示（`n_shots`）可以大幅提升模型以精确正确格式生成答案的稳健性，并提高总分。
</Tip>

## FAQs

<AccordionGroup>
<Accordion title="What does the BoolQ benchmark measure?">
BoolQ 是包含 16K 个自然产生的是非题（验证集 3.3K）的阅读理解基准，每题配有文章。这些问题在无提示的设置下产生。各基准的评分方式见[基准介绍](/docs/benchmarks-introduction)。
</Accordion>
<Accordion title="How is BoolQ scored?">
打分基于**精确匹配**：`overall_score` 是模型给出精确正确答案（即 'Yes' 或 'No'）的题目占总数的比例。范围为 0 到 1，1 表示完美表现。
</Accordion>
<Accordion title="What is the default n_shots for BoolQ?">
它默认为 `5`，不能超过该数量。使用 `n_shots` 参数可以在少样本提示中调低它。
</Accordion>
<Accordion title="How many problems does BoolQ evaluate by default?">
默认 `n_problems` 设为 3270，评估所有题目。可以传入较小的 `n_problems` 值来评估更少的题目。
</Accordion>
<Accordion title="Can using more few-shot prompts improve the BoolQ score?">
可以。通过 `n_shots` 使用更多少样本提示可以大幅提升模型以精确正确格式生成答案的稳健性，并提高 `overall_score`。
</Accordion>
<Accordion title="How do I run BoolQ on a custom LLM?">
定义基准，然后用你的模型调用 `evaluate()` 并读取 `overall_score`。使用任意自定义 LLM 见[基准测试指南](/docs/benchmarks-introduction#benchmarking-your-llm)。
</Accordion>
</AccordionGroup>
