## Generate Your Goldens

由于不涉及任何扎根的上下文，实例化 `Synthesizer` 时需要提供 `StylingConfig`，`deepeval` 的 `Synthesizer` 才知道应生成什么类型的 golden：

<Tabs>
<Tab title="单轮">

```python
from deepeval.synthesizer import Synthesizer
from deepeval.synthesizer.config import StylingConfig

styling_config = StylingConfig(
  input_format="Questions in English that asks for data in database.",
  expected_output_format="SQL query based on the given input",
  task="Answering text-to-SQL-related queries by querying a database and returning the results to users",
  scenario="Non-technical users trying to query a database using plain English.",
)

synthesizer = Synthesizer(styling_config=styling_config)
```

</Tab>
<Tab title="多轮">

```python
from deepeval.synthesizer import Synthesizer
from deepeval.synthesizer.config import ConversationalStylingConfig

conversational_styling_config = ConversationalStylingConfig(
  conversational_task="Answering text-to-SQL-related queries by querying a database and returning the results to users",
  scenario_context="Non-technical users trying to query a database using plain English.",
  participant_roles="Non-technical users trying to query a database using plain English."
)

synthesizer = Synthesizer(conversational_styling_config=conversational_styling_config,)
```

</Tab>
</Tabs>

最后，要在没有提供上下文的情况下生成合成 golden，只需提供你想生成的 golden 数量：

<Tabs>
<Tab title="单轮">

```python
from deepeval.synthesizer import Synthesizer
...

goldens = synthesizer.generate_goldens_from_scratch(num_goldens=25)
print(goldens)
```

</Tab>
<Tab title="多轮">

```python
from deepeval.synthesizer import Synthesizer
...

conversational_goldens = synthesizer.generate_conversational_goldens_from_scratch(num_goldens=25)
print(conversational_goldens)
```

</Tab>
</Tabs>

使用 `generate_goldens_from_scratch` 方法时有**一个**必填参数：

- `num_goldens`：要生成的 golden 数量。

## FAQs

<AccordionGroup>
<Accordion title="When should I generate goldens from scratch?">
当你的应用不依赖 RAG，或你想测试既有知识库之外的问题时使用。提供 `num_goldens` 设定生成数量。
</Accordion>
<Accordion title="Why is generate_goldens_from_scratch the least grounded method?">
由于没有提供文档或上下文，golden 不扎根于知识库——这是四种生成方法中扎根程度最低的。需要扎根的 golden 请使用 [generate_goldens_from_docs](/docs/synthesizer-generate-from-docs)。
</Accordion>
<Accordion title="How does the Synthesizer know what to generate without context?">
你必须提供 `StylingConfig`（多轮为 `ConversationalStylingConfig`），定义 `task` 、`scenario` 和输出格式，由它们代替扎根的上下文来引导生成。
</Accordion>
<Accordion title="Can my team generate goldens from scratch without code?">
可以。在 [Confident AI](https://www.confident-ai.com) 上你可以连接知识库并无代码地运行生成流水线——调整过滤、演化和样式，试验不同变体，并与团队协作处理产生的数据集。
</Accordion>
</AccordionGroup>
