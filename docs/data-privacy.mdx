## 使用 `deepeval` 时的隐私

默认情况下，`deepeval` 使用 **PostHog** 仅收集非常基础的遥测数据。具体收集以下内容：

- 事件名称（例如评估开始/完成）
- 使用的指标名称
- 评估是否在 Jupyter notebook 中运行
- 随机生成的匿名 UUID（不含用户或公司身份）
- 公网 IP 地址（仅用于粗略的区域分析）

明确排除个人可识别信息。你可以随时选择退出所有遥测：

```bash
export DEEPEVAL_TELEMETRY_OPT_OUT=1
```


PostHog 是这些数据的唯一去向。`deepeval` 不会在任何地方报告崩溃或异常。

## 使用 Confident AI 时的隐私

发送到 Confident AI 的所有数据都安全地存储在我们托管在 AWS 私有云中的数据库内（除非你的组织使用 VIP 计划）。**你的组织是唯一能够访问你所存数据的实体。**

我们理解从合规角度来看可能仍存在对数据安全的担忧。如需增强的安全性与功能，请考虑在[这里](https://confident-ai.com/pricing)升级你的会员。
