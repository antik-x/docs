## 模块化设计

DeepEval 提供搭建你自己的评估流水线所需的构件：

- [测试用例](/docs/evaluation-test-cases)：结构化你想评估的输入、输出、预期行为、上下文、工具与元数据。
- [数据集](/docs/evaluation-datasets)：组织可复用的金标（golden），用于回归测试、实验与 CI/CD。
- [指标](/docs/metrics-introduction)：定义输出、追踪与 Span 如何打分。
- [追踪与 Span](/docs/evaluation-llm-tracing)：捕获执行期间发生的事，让你既能评估完整运行，也能评估单个组件。
- [合成数据生成](/docs/synthetic-data-generation-introduction)：在样本不足时生成测试数据。

你可以通过 DeepEval 内置的工作流组合使用它们，也可以在系统需要更具体的组合方式时自行搭配。这个框架足够有主见，让评估可复现；但不会强迫你走某一条僵化的流水线。

## 告别凭感觉写 AI

对用 vibe coding 构建 AI 的人来说，DeepEval 是你迭代循环中的验证层。

与其让 Claude Code、Codex 等工具把你的智能体运行时从 LangChain 换成 Pydantic AI，或者换一个模型、改一句提示词，DeepEval 给出编码智能体实现自动驾驶式迭代循环所需要的定性结果。

我们希望你在端着一杯咖啡的同时就能构建可靠的智能体——即便是在 vibe coding 的时候。

## 快速本地迭代

对工程师而言，最快的循环是本地循环：运行智能体、检查追踪、定位失败的 Span、修补提示词或代码、再跑一次评估。

这个循环从本地开始，因为迭代在本地最快。当团队需要在结果上协作、比较回归、监控生产追踪，或与非工程师共享报告时，DeepEval 与 [Confident AI](https://www.confident-ai.com) 原生集成。

## 灵活的评估模型

DeepEval 围绕两种互补的模型设计。两者都能产生端到端评估；当你需要更细的粒度时，两者也都支持组件级评估。

### 基于测试用例的评估

当你已经知道输入和预期行为时使用它。这是 QA 工作流、回归套件、CI/CD 把关与端到端输出质量检查的最直接路径。想评估系统的某个特定部分时，也可以手动创建组件级测试用例。

### 基于追踪的评估

当你可以运行应用、想对执行期间发生的事打分时使用它：完整追踪、单个 Span、工具调用与智能体步骤。对 AI 智能体、使用工具的系统与多步应用来说，这是自然而然的路——最终答案不足以解释失败。

目标不是永远二选一。需要简单的质量把关时从测试用例开始；需要理解应用如何得出结果时再加上追踪。

## Pytest 原生

DeepEval 提供一流的 Pytest 集成。你可以把评估写在应用代码旁边、在本地运行，并在 CI/CD 中使用通过/失败结果。评估可以从快速实验起步，然后成长为保护后续变更的回归测试。

因为结果可以保存在本地，智能体编码工具也能检查与你相同的产物：失败的指标、原因、追踪与测试运行。评估因此不仅对人可用，也对帮你修改智能体的工具可用。

## 没有冷启动

好的评估需要样本。没有数据集，你很难判断一次提示词、模型或智能体的变更是否真的改善了质量，还是只对你碰巧手工测试的那一个例子有效。

当样本不足时，[合成数据生成](/docs/synthetic-data-generation-introduction)可以帮助你从文档、上下文或种子样本引导出一个数据集。这让你能在用户发现之前覆盖边界场景，而不是苦等足够的生产流量或一轮轮手工 QA 来积累覆盖。

## 需要时的企业平台

本地迭代应当保持快速，但团队最终会需要共享报告、回归分析、追踪可观测性、生产监控、数据集管理、提示词版本管理，以及与非工程师的协作。

DeepEval 与 [Confident AI](https://www.confident-ai.com) 原生集成来满足这些工作流，**需要 0 行额外代码。**你在本地运行的同一批评估，在团队需要平台时就能变成共享测试运行、实验、仪表盘与监控任务——你要做的只是配置一个 `CONFIDENT_API_KEY`。

## 有主见的原语，简单的 API

AI 变化很快，因此评估需要底下有稳定的概念。DeepEval 让原语保持有主见：测试用例描述发生了什么，指标描述如何打分，`assert_test()` 把结果变成一个测试。

同一套原语可以从一个测试用例扩展到数据集、追踪、Span 与生产监控。

如果你已经准备好运行第一个评估，从 [5 分钟快速上手](/docs/getting-started) 开始。
