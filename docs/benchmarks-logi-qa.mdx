**LogiQA** 基准由从逻辑能力测试中收集的 8,678 道多选题组成，评估 LLM 的逻辑推理能力。更多信息见 [LogiQA 论文](https://arxiv.org/abs/2007.04128)。

<Info>
LogiQA is derived from publicly available logical comprehension questions from China's **National Civil Servants Examination**. These questions are designed to evaluate candidates' critical thinking and problem-solving skills.
</Info>

## 参数

There are **TWO** optional arguments when using the `LogiQA` benchmark:

- [Optional] `tasks`: a list of tasks (`LogiQATask` enums), which specifies the subject areas for model evaluation. By default, this is set to all tasks. The list of `LogiQATask` enums can be found [here](#logiqa-tasks).
- [可选] `n_shots`：用于少样本学习的示例数量。**默认设为 5**，**不能超过 5**。

## 用法

The code below assesses a custom `mistral_7b` model ([click here](/guides/guides-using-custom-llms) to learn how to use ANY custom LLM) on categorical reasoning and sufficient conditional reasoning using 3-shot prompting.

```python
from deepeval.benchmarks import LogiQA
from deepeval.benchmarks.tasks import LogiQATask

# Define benchmark with specific tasks and shots
benchmark = LogiQA(
    tasks=[LogiQATask.CATEGORICAL_REASONING, LogiQATask.SUFFICIENT_CONDITIONAL_REASONING],
    n_shots=3
)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

该基准的 `overall_score` 范围为 0 到 1，1 表示完美表现，0 表示全部答错。模型分数基于**精确匹配**，通过确定模型给出精确正确选项的多选题占总题数的比例来计算。

<Tip>
因此，使用更多少样本提示（`n_shots`）可以大幅提升模型以精确正确格式生成答案的稳健性，并提高总分。
</Tip>

## LogiQA Tasks

The `LogiQATask` enum classifies the diverse range of reasoning categories covered in the LogiQA benchmark.

```python
from deepeval.benchmarks.tasks import LogiQATask

math_qa_tasks = [LogiQATask.CATEGORICAL_REASONING]
```

Below is the comprehensive list of available tasks:

- `CATEGORICAL_REASONING`
- `SUFFICIENT_CONDITIONAL_REASONING`
- `NECESSARY_CONDITIONAL_REASONING`
- `DISJUNCTIVE_REASONING`
- `CONJUNCTIVE_REASONING`

## 常见问题

<AccordionGroup>
<Accordion title="What does the LogiQA benchmark measure?">
LogiQA assesses an LLM's logical reasoning across various types of deductive reasoning, including categorical and disjunctive reasoning. It features 8,678 multiple-choice questions, each paired with a reading passage. See the [benchmarks introduction](/docs/benchmarks-introduction) for how scoring works across benchmarks.
</Accordion>
<Accordion title="How is LogiQA scored?">
Scoring is based on **exact matching**: the `overall_score` is the proportion of questions for which the model produces the precise correct multiple-choice answer (e.g. 'A' or 'C') out of the total. It ranges from 0 to 1, where 1 signifies perfect performance.
</Accordion>
<Accordion title="What is the default n_shots for LogiQA?">
It defaults to `5` and cannot exceed that. Use the `n_shots` argument to lower it for few-shot prompting.
</Accordion>
<Accordion title="Which reasoning tasks can I evaluate with LogiQA?">
Pass a list of `LogiQATask` enums to the `tasks` argument. Available tasks are `CATEGORICAL_REASONING` , `SUFFICIENT_CONDITIONAL_REASONING` , `NECESSARY_CONDITIONAL_REASONING` , `DISJUNCTIVE_REASONING` , and `CONJUNCTIVE_REASONING` . By default, all tasks are evaluated.
</Accordion>
<Accordion title="Can using more few-shot prompts improve the LogiQA score?">
Yes. Utilizing more few-shot prompts via `n_shots` can greatly improve the model's robustness in generating answers in the exact correct format and boost the `overall_score` .
</Accordion>
<Accordion title="How do I run LogiQA on a custom LLM?">
Define the benchmark, then call `evaluate()` with your model and read `overall_score` . See [benchmarking your LLM](/docs/benchmarks-introduction#benchmarking-your-llm) to learn how to use any custom LLM.
</Accordion>
</AccordionGroup>
