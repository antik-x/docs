**标签**：LLM-as-a-judge · 自定义 · 单轮 · 多模态

图像引用（image reference）指标评估图像**被伴随文本提及或解释**的准确程度。`deepeval` 的图像引用指标是 MLLM-Eval 内会自我解释的指标，会为其分数提供理由。

<Info>
图像引用评估包含文本以及随附检索或生成图像的 MLLM 响应。
</Info>

## Required Arguments

要使用 `ImageReference`，你需要在创建 [`LLMTestCase`](/docs/evaluation-test-cases#llm-test-case) 时提供以下参数：

- `input`
- `actual_output`

<Note>
请记住 `LLMTestCase` 的 `actual_output` 是字符串与 `Image` 对象的列表。如果实际输出中包含多张图像，最终分数是每张图像引用分数的平均值。
</Note>

`input` 与 `actual_output` 是创建 `LLMTestCase`（因此也是所有指标）的必备参数，即使它们可能不参与指标计算。更多信息见下方的 [How Is It Calculated](#how-is-it-calculated) 一节。

```python
from deepeval.test_case import LLMTestCase, MLLMImage
from deepeval.metrics import ImageReferenceMetric
from deepeval import evaluate

metric = ImageReferenceMetric(
    threshold=0.7,
    include_reason=True,
)
m_test_case = LLMTestCase(
    input=f"Provide step-by-step instructions on how to fold a paper airplane.",
    # Replace with your MLLM app output
    actual_output=f"""
        1. Take the sheet of paper and fold it lengthwise:
        {MLLMImage(url="./paper_plane_1", local=True)}
        2. Unfold the paper. Fold the top left and right corners towards the center.
        {MLLMImage(url="./paper_plane_2", local=True)}
        ...
    """
)


evaluate(test_cases=[m_test_case], metrics=[metric])
```

- [Optional] `threshold`: a number representing the minimum passing threshold. Can also be set to `None`（TypeScript 中为 `null`） to run the metric in [score-only mode](/docs/metrics-introduction#metric-thresholds). Defaulted to `0.5`.
- [可选] `strict_mode`：布尔值，设为 `True`（TypeScript 中为 `true`）时，把指标分数强制为二元：完美为 1，否则为 0。它还会覆盖当前阈值并将其设为 1。默认为 `False`（TypeScript 中为 `false`）。
- [可选] `async_mode`：布尔值，设为 `True` 时，启用[`measure()` 方法内的并发执行](/docs/metrics-introduction#measuring-metrics-in-async)。默认为 `True`。
  
- [可选] `verbose_mode`：布尔值，设为 `True`（TypeScript 中为 `true`）时，把计算该指标所用的中间步骤打印到控制台，具体见 [How Is It Calculated](#how-is-it-calculated) 一节。默认为 `False`（TypeScript 中为 `false`）。
- [Optional] `max_context_size`: a number representing the maximum number of characters in each context, as outlined in the [How Is It Calculated](#how-is-it-calculated) section. Defaulted to `None`（TypeScript 中为 `null`）.
- [可选] `flaky`：布尔值，设为 `True`（TypeScript 中为 `true`）时，[把指标标记为 flaky](/docs/metrics-introduction#flaky-metrics)。默认为 `False`（TypeScript 中为 `false`）。

## How Is It Calculated?

`ImageReference` 的分数按以下方式计算：

1. **单张图像引用**：每张图像的引用分数基于图像正上方与正下方的文本，受 `max_context_size`（字符数）限制。若未提供 `max_context_size`，则使用所有可用文本。公式为：

$$
R_i = f(\text{Context}_{\text{above}}, \text{Context}_{\text{below}}, \text{Image}_i)
$$

2. **最终分数**：整体的 `ImageReference` 分数是所有图像各自引用分数的平均：

$$
O = \frac{\sum_{i=1}^n R_i}{n}
$$

## FAQs

<AccordionGroup>
<Accordion title="图像引用与图像有用性、图像连贯性有何区别？">
图像引用检查每张图像是否被附近文本*提及或解释*，而 [`ImageHelpfulness`](/docs/multimodal-metrics-image-helpfulness) 检查理解价值、[`ImageCoherence`](/docs/multimodal-metrics-image-coherence) 检查叙述对齐。
</Accordion>
<Accordion title="输出包含多张图像时指标如何处理？">
每个 `MLLMImage` 依据其紧邻上下文打分，结果是所有图像的**平均值**（ `O = (ΣR_i) / n` ）。一张引用良好的图像无法掩盖文本从未解释的另一张。
</Accordion>
<Accordion title="最大上下文大小控制什么？">
It caps how many characters above and below each image feed its reference score. Defaults to `None`（TypeScript 中为 `null`） (all surrounding text); lower it when images sit close together.
</Accordion>
<Accordion title="图像引用分数低通常说明什么？">
图像插入时周围没有指向它的文本——例如两张步骤之间放了一张图，但步骤从未提到它。检查 `metric.reason` 可看到是哪张图像缺少支撑文本。
</Accordion>
</AccordionGroup>
