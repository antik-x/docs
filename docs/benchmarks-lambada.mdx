---
title: LAMBADA
---

**LAMBADA**（_LAnguage Modeling Broadened to Account for Discourse Aspects_）评估 LLM 理解上下文和语篇的能力。该数据集包含 10,000 段取自 BooksCorpus 的文章，每段都要求 LLM 预测句子的最后一个词。想更深入探索该数据集，请查阅 [LAMBADA 原始论文](https://arxiv.org/abs/1606.06031)。

<Tip>
`LAMBADA` 数据集专门设计为人类在没有前文的情况下无法预测最后一句的末词，使其成为评估模型**广泛理解能力**的有效基准。
</Tip>

## Arguments

使用 `LAMBADA` 基准时有**两个**可选参数：

- [可选] `n_problems`：用于模型评估的题目数量。默认为 5153（所有题目）。
- [可选] `n_shots`：用于少样本学习的示例数量。**默认设为 5**，**不能超过 5**。

## Usage

下面的代码评估自定义 `mistral_7b` 模型（[点击这里](/docs/benchmarks-introduction#benchmarking-your-llm)了解如何使用**任意**自定义 LLM），使用 3-shot CoT 提示评估其在 `LAMBADA` 10 道题上的表现。

```python
from deepeval.benchmarks import LAMBADA

# Define benchmark with n_problems and shots
benchmark = LAMBADA(
    n_problems=10,
    n_shots=3,
)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

该基准的 `overall_score` 范围为 0 到 1，1 表示完美表现，0 表示全部答错。模型分数基于**精确匹配**，通过确定模型预测出**精确正确目标词**的题目占总题数的比例来计算。

<Tip>
因此，使用更多少样本提示（`n_shots`）可以大幅提升模型以精确正确格式生成答案的稳健性，并提高总分。
</Tip>

## FAQs

<AccordionGroup>
<Accordion title="What does the LAMBADA benchmark measure?">
LAMBADA 评估 LLM 理解上下文和语篇的能力。它包含 10,000 段取自 BooksCorpus 的文章，每段都要求模型预测句子的最后一个词。各基准的评分方式见[基准介绍](/docs/benchmarks-introduction)。
</Accordion>
<Accordion title="How is LAMBADA scored?">
打分基于**精确匹配**：`overall_score` 是模型预测出精确正确目标词的题目占总数的比例。范围为 0 到 1，1 表示完美表现。
</Accordion>
<Accordion title="What is the default n_shots for LAMBADA?">
它默认为 `5`，不能超过该数量。使用 `n_shots` 参数可以在少样本提示中调低它。
</Accordion>
<Accordion title="How many problems does LAMBADA evaluate by default?">
默认 `n_problems` 设为 5153，评估所有题目。可以传入较小的 `n_problems` 值来评估更少的题目。
</Accordion>
<Accordion title="Why is LAMBADA considered a good comprehension benchmark?">
该数据集经过专门设计：没有前文的话，人类也无法预测最后一句的末词，因此它是评估模型**广义理解能力**的有效基准。
</Accordion>
<Accordion title="How do I run LAMBADA on a custom LLM?">
定义基准，然后用你的模型调用 `evaluate()` 并读取 `overall_score`。使用任意自定义 LLM 见[基准测试指南](/docs/benchmarks-introduction#benchmarking-your-llm)。
</Accordion>
</AccordionGroup>
