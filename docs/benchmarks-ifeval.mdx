**IFEval（面向大语言模型的指令遵循评估
）**是评估语言模型指令遵循能力的基准。
它测试指令遵循的多个方面，包括格式合规、约束
遵循、输出结构要求和特定指令类型。

<Tip>
`deepeval` 的 `IFEval` 实现基于 Google 的[原始研究论文](https://arxiv.org/abs/2311.07911)。
</Tip>

## 参数

使用 `IFEval` 基准时只有**一个**可选参数：

- [可选] `n_problems`：限制基准将评估的测试用例数量。默认为 `None`。

## 用法

下面的代码评估自定义 `mistral_7b` 模型（[点击这里](/docs/benchmarks-introduction#benchmarking-your-llm)了解如何使用**任意**自定义 LLM），使用 3-shot 学习评估其在高中计算机科学与天文学任务上的表现。

```python
from deepeval.benchmarks import IFEval

# Define benchmark with 'n_problems'
benchmark = IFEval(n_problems=5)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

## 常见问题

<AccordionGroup>
<Accordion title="What does the IFEval benchmark measure?">
IFEval 评估语言模型的指令遵循能力。它测试多个方面，包括格式合规、约束遵循、输出结构要求和特定指令类型。各基准的评分方式见[基准介绍](/docs/benchmarks-introduction)。
</Accordion>
<Accordion title="What arguments does the IFEval benchmark accept?">
只有一个可选参数 `n_problems` ，用于限制基准将评估的测试用例数量。默认为 `None` 。
</Accordion>
<Accordion title="What does the n_problems argument do?">
`n_problems` 限制基准将评估的测试用例数量。默认为 `None` ，可设为一个整数（例如 `5` ）来评估更小的子集。
</Accordion>
<Accordion title="What research is deepeval's IFEval implementation based on?">
deepeval 的 `IFEval` 实现基于 Google 的原始研究论文。更多信息见[基准介绍](/docs/benchmarks-introduction) 。
</Accordion>
<Accordion title="Does IFEval support tasks or n_shots arguments?">
不。`IFEval` 只暴露一个可选参数 `n_problems` 。不接受 `tasks` 列表或 `n_shots` 参数。
</Accordion>
<Accordion title="How do I read the result of an IFEval run?">
调用 `evaluate()` 后，读取 `overall_score` 属性查看模型在所评估的指令遵循测试用例上的表现。
</Accordion>
<Accordion title="How do I run IFEval on a custom LLM?">
定义基准，然后用你的模型调用 `evaluate()` 并读取 `overall_score` 。使用任意自定义 LLM 见[评估你的 LLM](/docs/benchmarks-introduction#benchmarking-your-llm)。
</Accordion>
</AccordionGroup>
