**ARC（AI2 Reasoning Challenge）**是用于对语言模型推理能力进行基准测试的数据集。该基准包含 8,000 道来自 3 至 9 年级科学考试的多选题。数据集包含两种模式：_easy_ 和 _challenge_，后者包含需要高级推理的更难题目。

<Tip>
要了解数据集及其构建方式的更多信息，可[阅读原始论文](https://arxiv.org/pdf/1803.05457v1)。
</Tip>


## 参数
使用 `ARC` 基准时有**三个**可选参数：
- [可选] `n_problems`：用于模型评估的题目数量。默认为每种基准模式下所有可用题目。
- [可选] `n_shots`：用于少样本学习的示例数量。**默认设为 5**，**不能超过 5**。
- [可选] mode：`ARCMode` 枚举，选择评估模式。默认为 `ARCMode.EASY`。`deepeval` 目前支持 2 种模式：**EASY 和 CHALLENGE**。

<Info>
`EASY` 和 `CHALLENGE` 模式都由**多选**题组成。但 `CHALLENGE` 的题目更难，需要更高级的推理。
</Info>

## 用法

下面的代码评估自定义 `mistral_7b` 模型（[点击这里](/docs/benchmarks-introduction#benchmarking-your-llm)了解如何使用**任意**自定义 LLM），在 EASY 模式下评估其在 `ARC` 100 道题上的表现。

```python
from deepeval.benchmarks import ARC
from deepeval.benchmarks.modes import ARCMode

# Define benchmark with specific n_problems and n_shots in easy mode
benchmark = ARC(
    n_problems=100,
    n_shots=3,
    mode=ARCMode.EASY
)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

`overall_score` 范围为 0 到 1，表示跨任务的预测准确率。两种模式的表现都用**精确匹配**评分器度量，关注正确答案的数量。

## 常见问题

<AccordionGroup>
<Accordion title="What does the ARC benchmark measure?">
ARC（AI2 推理挑战）通过来自 3-9 年级科学考试的 8,000 道多选题来评估 LLM 的**推理能力**。
</Accordion>
<Accordion title="EASY 和 CHALLENGE 模式是什么？">
`mode` 参数接受一个 `ARCMode` 枚举，默认为 `ARCMode.EASY`。`EASY` 与 `CHALLENGE` 都由多选题组成，但 `CHALLENGE` 的题目更难，需要更高级的推理。
</Accordion>
<Accordion title="ARC 如何打分？">
`overall_score` 范围为 0 到 1，表示各任务中准确预测的比例。两种模式都用**精确匹配**打分器衡量正确答案的数量。跨基准的打分方式见[基准简介](/docs/benchmarks-introduction)。
</Accordion>
<Accordion title="ARC 的默认 n_shots 是多少？">
`n_shots` 参数默认设为 `5`，**不能超过 5**。它控制少样本学习使用的示例数量。
</Accordion>
<Accordion title="ARC 默认评估多少道题？">
`n_problems` 参数默认为每种基准模式下所有可用题目。可以调低它（例如 `n_problems=100`）以更快地运行评估。
</Accordion>
<Accordion title="如何在自定义 LLM 上运行 ARC？">
把你的模型包装在 `DeepEvalBaseLLM` 中，创建 `ARC(n_problems=100, n_shots=3, mode=ARCMode.EASY)` 基准，调用 `benchmark.evaluate(model=mistral_7b)` 后读取 `benchmark.overall_score`。使用任意自定义 LLM 见[基准测试指南](/docs/benchmarks-introduction#benchmarking-your-llm)。
</Accordion>
</AccordionGroup>
