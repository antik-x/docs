**标签**：LLM-as-a-judge · 单轮 · 无参考 · 多模态

MCP 使用（MCP Use）指标用于评估**基于 MCP 的 LLM 智能体对其可访问的 MCP 服务器的利用效率**。它使用 LLM-as-a-judge 评估被调用的 MCP 原语以及 LLM 应用生成的参数。

## Required Arguments

要使用 `MCPUseMetric`，你需要在创建 [`LLMTestCase`](https://www.deepeval.com/docs/evaluation-test-cases) 时提供以下参数：

- `input`
- `actual_output`
- `mcp_servers`

如果使用了 `mcp_tools_called`、`mcp_resources_called` 与 `mcp_prompts_called`，也需要提供它们，评估才能进行。点击[这里](#how-is-it-calculated)了解它的计算方式。

## Usage

`MCPUseMetric` 可用于带 MCP 参数的单轮 `LLMTestCase`。点击[这里](https://www.deepeval.com/docs/evaluation-mcp#single-turn)了解如何创建 MCP 单轮测试用例。

```python
from deepeval.test_case import LLMTestCase, MCPServer

    input="...", # Your input here
    actual_output="...", # Your LLM app's final output here
    mcp_servers=[MCPServer(...)] # Your MCP server's data
    # MCP primitives used (if any)
)

metric = MCPUseMetric()

# To run metric as a standalone
# metric.measure(convo_test_case)
# print(metric.score, metric.reason)

evaluate([test_case], [metric])
```

## How Is It Calculated

`MCPUseMetric` 的分数按以下公式计算：

$$
\text{MCP Use Score} = \text{AlignmentScore(Primitives Used, Primitives Available)}
$$

**AlignmentScore** 由评估模型评判，依据是调用了哪些原语、以及针对用户输入生成的参数。

<Info>
`MCPUseMetric` 评估是否以正确的参数调用了正确的工具；也就是说，如果以上可选参数都未提供，`MCPUseMetric` 会评估调用任何可用原语是否会更好。
</Info>

## FAQs

<AccordionGroup>
<Accordion title="When should I use MCP Use instead of Multi-Turn MCP Use?">
单轮 [LLMTestCase](https://www.deepeval.com/docs/evaluation-test-cases)（一对 `input` / `actual_output`）用 `MCPUseMetric`。跨对话的 MCP 使用情况，则在 `ConversationalTestCase` 上用 `MultiTurnMCPUseMetric`。
</Accordion>
<Accordion title="What MCP data do I have to populate for the metric to actually run?">
`input`、`actual_output` 与 `mcp_servers`（可用原语），加上实际被调用的原语——`mcp_tools_called`、`mcp_resources_called`、`mcp_prompts_called`。见[创建 MCP 单轮测试用例](https://www.deepeval.com/docs/evaluation-mcp#single-turn)。
</Accordion>
<Accordion title="The agent picked the wrong tool or resource — how do I debug that?">
`AlignmentScore` 低意味着原语次优或参数不佳。开启 `verbose_mode` 或读取 `metric.reason`，查看裁判对更好选择的理由。
</Accordion>
<Accordion title="如果我不传入任何被调用的原语会怎样？">
没有 `mcp_tools_called`、`mcp_resources_called` 或 `mcp_prompts_called` 时，`MCPUseMetric` 会评判调用任何*可用*原语本是否有帮助——即评估「完全不使用 MCP」这一决定本身。
</Accordion>
</AccordionGroup>
