**TruthfulQA** 基准衡量 LLM 在回答问题时是否真实，评估模型避免常见错误信念的能力。更多信息见 [TruthfulQA 论文](https://github.com/sylinrl/TruthfulQA)。

## 参数

There are **TWO** optional arguments when using the `TruthfulQA` benchmark:

- [Optional] `tasks`: a list of tasks (`TruthfulQATask` enums), which specifies the subject areas for model evaluation. By default, this is set to all tasks. The complete list of `TruthfulQATask` enums can be found [here](#truthfulqa-tasks).
- [Optional] mode: a `TruthfulQAMode` enum that selects the evaluation mode. This is set to `TruthfulQAMode.MC1` by default. `deepeval` currently supports 2 modes: **MC1 and MC2**.

<Info>
**TruthfulQA** consists of multiple modes using the same set of questions. **MC1** mode involves selecting one correct answer from 4-5 options, focusing on identifying the singular truth among choices. **MC2** (Multi-true) mode, on the other hand, requires identifying multiple correct answers from a set. Both MC1 and MC2 are **multiple choice** evaluations.
</Info>

## 用法

The code below assesses a custom `mistral_7b` model ([click here to learn how to use **ANY** custom LLM](/docs/benchmarks-introduction#benchmarking-your-llm)) on Advertising and Fiction tasks in `TruthfulQA` using MC2 mode evaluation.

```python
from deepeval.benchmarks import TruthfulQA
from deepeval.benchmarks.tasks import TruthfulQATask
from deepeval.benchmarks.modes import TruthfulQAMode

# Define benchmark with specific tasks and shots
benchmark = TruthfulQA(
    tasks=[TruthfulQATask.ADVERTISING, TruthfulQATask.FICTION],
    mode=TruthfulQAMode.MC2
)

# Replace 'mistral_7b' with your own custom model
benchmark.evaluate(model=mistral_7b)
print(benchmark.overall_score)
```

该基准的 `overall_score` 范围为 0 到 1，1 表示完美表现，0 表示全部答错。模型分数基于**精确匹配**，通过确定模型给出精确正确答案的题目占总题数的比例来计算。

Conversely, MC2 mode employs a **truth identification** scorer, which evaluates the extent of correctly identified truthful answers (quantifying accuracy by comparing sorted lists of predicted and target truthful answer IDs to determine the percentage of accurately identified truths).

<Tip>
Use **MC1** as a benchmark for pinpoint accuracy and **MC2** for depth of understanding.
</Tip>

## 常见问题

<AccordionGroup>
<Accordion title="What does the TruthfulQA benchmark measure?">
`TruthfulQA` assesses how truthfully an LLM answers questions. It includes 817 questions across 38 topics like health, law, finance, and politics, targeting common **misconceptions ** that some humans would falsely answer due to false belief.
</Accordion>
<Accordion title="Which tasks can I run with TruthfulQA?">
You can pass a list of `TruthfulQATask` enums to the `tasks` argument, for example `ADVERTISING` or `FICTION` . By default, all available tasks are evaluated.
</Accordion>
<Accordion title="What are the MC1 and MC2 modes?">
The `mode` argument takes a `TruthfulQAMode` enum and defaults to `TruthfulQAMode.MC1` . **MC1** involves selecting one correct answer from 4-5 options, while **MC2** (Multi-true) requires identifying multiple correct answers from a set. Both are multiple-choice evaluations.
</Accordion>
<Accordion title="How is TruthfulQA scored?">
The `overall_score` ranges from 0 to 1. MC1 uses an **exact match** scorer focused on singular correct answers, while MC2 uses a **truth identification** scorer that compares sorted lists of predicted and target truthful answer IDs. See the [benchmarks introduction](/docs/benchmarks-introduction) for more on scoring.
</Accordion>
<Accordion title="Should I use MC1 or MC2?">
Use **MC1** as a benchmark for pinpoint accuracy and **MC2** for depth of understanding. Both modes use the same set of questions, so you can compare them directly.
</Accordion>
<Accordion title="How do I run TruthfulQA on a custom LLM?">
Wrap your model in `DeepEvalBaseLLM` , create a benchmark with `TruthfulQA(tasks=[...], mode=TruthfulQAMode.MC2)` , and call `benchmark.evaluate(model=mistral_7b)` before reading `benchmark.overall_score` . See the [benchmarking guide](/docs/benchmarks-introduction#benchmarking-your-llm) for using any custom LLM.
</Accordion>
</AccordionGroup>
